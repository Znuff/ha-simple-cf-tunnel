# Simple Cloudflare Tunnel

Reach Home Assistant through Cloudflare without opening ports:

- **Permanent access** on your own hostname, set up from the panel with a
  scoped Cloudflare API token.
- **Temporary access** on a random `trycloudflare.com` URL with an expiry
  timer, no Cloudflare account needed.

See the Documentation tab for setup and security notes.
