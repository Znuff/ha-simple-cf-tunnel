Share Home Assistant on a random trycloudflare.com URL. No Cloudflare account needed. The URL stops working for good when the tunnel stops.

Home Assistant doesn't trust this add-on as a reverse proxy yet. Visitors will get "400: Bad Request" until you fix this.

In Settings → System → Network → HTTP server, enable "Trust X-Forwarded-For" and add 172.30.33.0/24 as a trusted proxy. Or add this to configuration.yaml:

http:
  use_x_forwarded_for: true
  trusted_proxies:
    - 172.30.33.0/24

Then restart Home Assistant and

Anyone with the URL can reach your Home Assistant login page. Give the person their own non-admin user (Settings → People), and remove it afterwards.
